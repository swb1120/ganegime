가는 김에 0.6.4 주차 중 조작 제한
2026.11.13 · 장선웅 · ai.ganegime.app.release · versionCode 10

동작
차량 속도가 0이고 P단인 상태가 1초 이상 확인되어야 조작할 수 있습니다.
D/R/N단은 멈춰 있어도 잠깁니다. 양수·음수 속도 모두 주행으로 처리합니다.
초기 상태, 권한 없음, 읽기 오류, 유효하지 않은 값, 오래된 값은 잠금 상태입니다.
검색·일정·설정·비교 시연·내비 전송을 함께 막습니다. 기존 키보드 연결의 입력도 다시 검사합니다.
주행으로 바뀌면 설정 대화상자를 닫고, 아직 전송 전인 내비 요청을 취소합니다.
전송을 완료한 차량 내비의 경로 안내는 취소하지 않습니다.
주차가 다시 확인되면 검색창의 입력과 작성 중인 일정을 유지한 채 조작을 재개합니다.

구현
Pleos의 Android Automotive CarPropertyManager에서 PERF_VEHICLE_SPEED와 GEAR_SELECTION을 읽습니다.
속도는 m/s, P단 값은 4입니다. 속도 5 Hz 구독과 주기적 조회, 단조 증가 시계를 사용합니다.
속도의 VHAL 타임스탬프와 값 수신의 유효기간은 2.5초입니다. 기어는 ON_CHANGE 속성이므로 주기적 읽기로 상태를 확인합니다.
차량 서비스 연결 해제 시 잠급니다. 앱 UI를 숨기는 것과 별도로 터치·키보드·네이티브 호출을 검사합니다.
차량 상태를 변경하는 권한이나 앱 안의 잠금 해제 우회 스위치는 없습니다.
앱에서 차량 속도·기어를 파일이나 Logcat에 기록하지 않습니다.

Pleos 에뮬레이터 확인
환경: Pleos Connect 2.1, Android 14/API 34, x86_64, emulator-5554, user 10.
검증 APK는 서명된 release이며 디버그 APK나 가짜 차량 상태 공급자를 사용하지 않았습니다.
공식 Virtual Console의 차량 신호를 변경해 앱까지 전달했습니다.
- P/0 → 조작 허용
- D/주행 신호 → 잠금, 기존 키보드 삽입·삭제·조합 입력 차단, 터치 차단
- 잠금 중 검색 요청 → PARK_REQUIRED, 내비 요청 → ignored
- D/0 및 N/0 → 잠금 유지
- R/주행 신호 → 잠금
- 다시 P/0 → 검색어 유지, 조작 재개
- 열린 네이티브 서버 설정 창 → D 전환 시 닫힘
- 비교 시연 화면 → 같은 잠금 적용
- 차량 속도 권한을 실제로 철회한 뒤 앱 실행 → 권한 안내와 잠금 확인, 검사 후 권한 복구
- 실제 상점 검색·교통 계산·목적지/경유지 내비 전달 회귀 시험 통과
- 이전 위치 로그 삭제·민감한 입력의 진단 유출 방지 회귀 시험 통과
Pleos 시스템 자체 주행 제한 화면도 함께 표시됩니다. 시스템 제한을 우회하도록 앱을 등록하지 않았습니다.

검증 구분과 한계
DrivingGuardTest 2건(차량 신호 통합 시험 1건과 상태 정책 경계 시험 1건), PrivacyRegressionTest 2건,
SubmissionVideoTest#liveRecording 1건을 통과했습니다. 별도 호스트 검사로 권한 철회를 확인했습니다.
알 수 없는 값·NaN·오래된 값·짧은 정차·후진은 상태 정책 시험에 포함됩니다.
실제 CarService 프로세스 장애와 실차에서의 CAN 신호 장애는 재현하지 않았습니다.
Virtual Console 창을 닫아도 에뮬레이터의 VHAL은 마지막 값을 계속 제공할 수 있으므로, 창 닫기를 신호 장애 검증으로 계산하지 않았습니다.
센서·OS가 제공하는 신호의 정확성 및 실제 차량별 동작은 별도 실차 검증이 필요합니다.

직접 재현
1. 공식 Pleos 에뮬레이터에 APK를 기존 앱 위로 업데이트합니다. 앱 삭제는 필요하지 않습니다.
2. 처음 요청하는 차량 속도 권한을 허용합니다. 거부했다면 시스템 설정에서 허용 후 앱을 다시 엽니다.
3. adb -s <에뮬레이터 ID> forward tcp:8088 tcp:8088
4. PC에서 http://127.0.0.1:8088/ 를 열어 Virtual Console을 유지합니다.
5. P/속도 0에서 입력하고 D·가속, D·속도 0, 다시 P 순서로 바꿔 확인합니다.
   R단에서는 Pleos 후방 카메라가 앞으로 열립니다. P로 전환한 뒤 가는 김에 앱을 다시 열어 입력 유지와 잠금 해제를 확인합니다.
6. 주차 상태에서 기존 심사용 접속 코드로 검색·계산·내비 전달을 확인합니다.
이 포트 전달은 개발용 차량 신호 조절에만 쓰입니다. 앱의 상점 검색·일정 서버는 기존 클라우드입니다.
